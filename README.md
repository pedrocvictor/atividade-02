# Algoritmos Clássicos — Atividade Unifor

Implementação de 6 algoritmos clássicos (número primo, somatório, Fibonacci, MDC, quicksort e contagem em intervalo) em Java e JavaScript, mais uma aplicação web para executá-los.

## Arquivos

- `Algoritmos.java` — implementação em Java
- `algoritmos.js` — implementação em JavaScript (Node.js)
- `algoritmos.html` — aplicação web (front-end) para rodar os algoritmos direto no navegador

## Como executar

**Java**
```
javac Algoritmos.java
java Algoritmos
```

**JavaScript (Node.js)**
```
node algoritmos.js
```

**App web**
Basta abrir o `algoritmos.html` em qualquer navegador (ou publicar via GitHub Pages).
